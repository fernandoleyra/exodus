# Code of conduct

This project handles data about human migration. That subject attracts bad-faith argument,
and the standard here is accordingly plain.

## Expected

- Argue with evidence. A claim about the data should come with a source.
- Assume good faith in others and make it easy to assume in you.
- Accept correction. Being wrong in public is the normal cost of working openly.

## Not accepted

- Dehumanising language about migrants, refugees or any group. The people in this dataset
  are people. Language that treats them as a flood, a wave, an invasion or a burden is not
  a stylistic preference we disagree with; it is out of scope for this project.
- Harassment, personal attacks, or sustained disruption.
- Using this project, its issue tracker or its data to advance targeting of any community.

## Enforcement

Maintainers may remove comments, close contributions and block accounts. Report concerns
privately through GitHub's Security tab or by opening an issue if it is safe to do so
publicly.

Adapted in spirit from the Contributor Covenant, with the migration-specific clause added
deliberately.
