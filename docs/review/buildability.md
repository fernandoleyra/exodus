## CORRECTNESS DEFECTS IN THE GIVEN CODE AND FORMULAS

**18. §6.4 `contiguousF32` does not compile under `noUncheckedIndexedAccess`.** `values[chunk.offset + i]` is `number | undefined`; assigning it to `out[o++]` (a `Float32Array` index) is a type error. **19. §5.3.5 POADR uses the wrong life-table denominator.** `e(a) = Σ_{x ≥ a} L(x) / L(a) − 0.5` is not remaining life expectancy. The identity is `e(a) = T(a)/l(a)` where `T(a) = Σ_{x≥a} L(x)` and `l(a)` is survivors at exact age `a`. Dividing by `L(a)` (person-years lived in the interval) biases `e(a)` by roughly `l(a)/L(a)` — small at young ages, material at 65+, and it silently shifts `α(c,y)` and therefore every POADR figure on `/place` and `/headroom`. `wpp_life.parquet` is specified to carry `L(a)` only, so the correct form is not even computable from the shipped table.
**Fix:** add `lx` to `wpp_life.parquet`'s column list in §3.3 and §3.8, correct the formula to `T(a)/l(a)`, and add a golden test: a synthetic life table with `e(65) = 15` exactly must yield `oldAgeThreshold === 65` (the test is already named in §5.3.7 and would currently fail against the specified formula).
