# Research corpus

Verified research packs produced while designing the Exodus MVP build prompt.
Each pack was written by a research agent with live web access and then attacked
by an adversarial fact-checker whose job was to break it: every URL, endpoint,
dataset vintage, licence string, library version and published coefficient was
re-probed against the live service. Claims that could not be confirmed were
deleted or marked `[UNVERIFIED]`; confirmed ones carry `[verified]`.

Treat `[UNVERIFIED]` as "check before you code against it, and fall back to the
committed snapshot rather than inventing an endpoint".
